🩸 Blood Connect

Blood Connect is a simple blood donation and blood bank management website built using HTML, CSS, and JavaScript.

Features

🏠 Home page
🩸 Blood donor registration
🔍 Find blood donors
📦 View blood stock
📋 Submit blood requests
📱 Responsive design

Technologies Used

HTML
CSS
JavaScript

How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Open `admin.html` in a web browser.

Purpose

The main purpose of this project is to make blood donation and finding blood donors easier through a simple website.
